# 交利を Word のアドインとして使う

Word の本文(選んだ範囲、または文書全体)を、交利の縦書きエディタで編集し、Word に書き戻すためのアドインです。Windows・Mac のどちらでも、ターミナルは使いません。

## 仕組み

- Word の「ホーム」タブに「交利で編集」ボタンが付き、押すと右側に作業ウィンドウが開きます。
- 「選択範囲を交利で開く」か「文書全体を交利で開く」を押すと、大きなウィンドウで交利が開き、Word の本文が読み込まれます。
- 編集して「Wordに反映して閉じる」を押すと、Word の本文が置き換わります。
- 作業ウィンドウもエディタも、GitHub Pages に置いた交利のページを読み込んで動きます。文章は利用者のパソコンの中だけで受け渡され、サーバーには送られません。

## Word への反映のしかた(2通り)

編集したウィンドウの下に、2つのボタンがあります。

**「Wordに反映(見た目そのまま・画像)」**
交利のページを、表示されているとおりに画像にして Word に入れます。字の配置、振り仮名、送り仮名、訓点、熟字訓、傍線・波線、外字まで、エディタの見た目になります。ページごとに1枚の画像で、ページが複数あれば、画像が続けて並びます。

- 画像なので、Word の中で字として選んだり、検索したりはできません(画像の代替テキストには、本文を入れてあります)。
- 画像の幅は、ボタンの横の選択で「縦向きの用紙(15.5cm)」か「横向きの用紙(24cm)」を選びます。入れたあとに、Word で画像の大きさを変えることもできます。
- 交利のページは横長なので、字を大きく見せたいときは、Word の用紙を横向きにして「横向きの用紙」を選んでください。

**「Wordに反映(文字・ルビ)」**
Word の文字として入れます。Word で検索や文字の編集ができます。ただし、見た目は近似です。

| 交利 | Word での表現 |
|---|---|
| 本文・句読点・括弧 | そのままの文字 |
| 振り仮名・熟字訓 | ルビ |
| 送り仮名・訓点・左の振り仮名/送り仮名 | 字の後ろに、小さい字で続ける |
| 傍線・波線 | 下線・波線の下線 |
| 字体組立で作った字(外字) | 「〓」 |

どちらの方法でも、交利で開いた範囲は文書の中に記録されます。**Word 側で本文を直さなければ**、次に開くとき注釈や外字も元どおりに戻ります。Word 側で本文を直した範囲は、その時点の本文だけが読み込まれます(画像にした範囲は、文字を直せないので、いつも元どおりに戻ります)。

## 読み込み方(1回だけ)

1. `manifest.xml` をテキストエディタで開き、`https://YOUR-NAME.github.io/YOUR-REPO` を、交利を公開している GitHub Pages のアドレスに置き換えて保存します(10 か所。検索と置換で一度にできます)。
2. 次のどちらかの方法で、Word に読み込みます。

### Mac の Word(デスクトップ)

1. Finder のメニュー「移動」→「フォルダへ移動」を開き、`~/Library/Containers/com.microsoft.Word/Data/Documents/wef` と入力して開きます(`wef` フォルダが無ければ、新規フォルダとして作ります)。
2. その中に `manifest.xml` をコピーします。
3. Word を開き直し、「挿入」→「アドイン」→「個人用アドイン」(または「マイ アドイン」)から「交利」を選びます。

### Windows の Word(デスクトップ)

1. `manifest.xml` を入れた専用のフォルダ(例: `C:\kouri-addin`)を作り、右クリック →「プロパティ」→「共有」でそのフォルダを共有します。表示される `\\パソコン名\kouri-addin` のようなアドレスを控えます。
2. Word の「ファイル」→「オプション」→「セキュリティ センター」→「セキュリティ センターの設定」→「信頼できるアドイン カタログ」に、控えたアドレスを入れて「カタログの追加」を押し、「メニューに表示する」にチェックを入れて、Word を開き直します。
3. 「挿入」→「アドイン」→「個人用アドイン」→「共有フォルダー」から「交利」を選びます。

### Word on the web(Microsoft 365 のブラウザ版。Windows・Mac 共通)

1. 新しい文書を開き、「挿入」→「アドイン」→「個人用アドイン」→「マニフェストをアップロード」から `manifest.xml` を選びます。

## 公開するファイル

次のファイルを、交利のほかのファイルと同じ場所(GitHub のリポジトリ)に置きます。

- `addin/manifest.xml`(アドレスを書き換えたもの)、`addin/taskpane.html`、`addin/taskpane.js`、`addin/ooxml.js`、`addin/icon-16.png`・`icon-32.png`・`icon-80.png`
- `js/word-bridge.js`
- `index.html`(アドイン用の受け渡し部分を追加したもの)

## 注意

- アドインの読み込みには、交利が **https** で公開されている必要があります(GitHub Pages は https です)。
- 交利で開いた範囲は、Word の「内容コントロール」(タイトル「交利」)で囲まれます。範囲ごと消すと、注釈の記録は使われなくなります。
- Word でアドインが動いたかの確認は、実際の Word で行ってください(この README の手順と変換部分は、Word を使わずに確認しています)。
